# ArchiLeaks GitHub Pages Kurulum

1. Bu klasördeki `index.html` dosyasını repo kök dizinine koy.
2. GitHub > Settings > Pages altında branch olarak `main` ve folder olarak `/root` seç.
3. Yayın öncesi `index.html` içindeki `https://www.archileaks.com/` canonical, Open Graph ve sitemap URL'lerini kendi domaininle değiştir.
4. Google reklamları için `ca-pub-REPLACE_WITH_YOUR_ID`, `REPLACE_NATIVE_SLOT`, `REPLACE_RIGHT_RAIL_SLOT` alanlarını gerçek değerlerle değiştir ve yorum satırındaki AdSense scriptini aç.
5. Canlı ürün için KVKK, çerez onayı, Supabase Auth, moderasyon kuyruğu ve n ≥ 5 yayın eşiğini backend tarafında zorunlu uygula.
